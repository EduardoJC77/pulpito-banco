# Púlpito · banco de sermões

Pacote de conteúdo do aplicativo Púlpito, um guia de bolso para quem prega.

- `indice.json`: versão do banco e lista de sermões. O aplicativo consulta este arquivo ao abrir.
- `pacote.json`: sermões, estilos de pregar, catálogo de temas e os versos citados.

Texto bíblico: João Ferreira de Almeida, edição de 1911 (domínio público), com a ortografia atualizada.

Os dois arquivos são gerados por um script. Não edite à mão.
